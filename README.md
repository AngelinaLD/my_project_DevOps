# Task Service API

Простое REST API для управления задачами, упакованное в Docker-контейнер.

task-service — учебный проект, демонстрирующий упаковку API-приложения в Docker-контейнер.

Задача: сервис позволяет получать список задач и проверять состояние приложения.

Технологии:

- Python 3.14.7
- Flask 3.1.3
- Docker

Структура проекта:
task-service/

- app.py #основное приложение
- requirements.txt #зависимости Python
- Dockerfile #инструкция сборки образа
- .dockerignore #исключения для контекста сборки
- README.md #документация
